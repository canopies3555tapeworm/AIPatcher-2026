## FAQ

### Is OmniPatch safe to use?

OmniPatch is designed to modify application files locally. While we ensure it is free from tool, modifying software may trigger false positives from anticomponent programs. Please review and proceed at your discretion.

### Which AI applications are supported?

OmniPatch supports patching ChatGPT, Claude, Perplexity, Microsoft Copilot, Cursor, GitHub Copilot, Devin, and JetBrains AI Assistant.

### How often is OmniPatch updated?

We aim to release updates within 48 hours after a major version release of any supported AI application to ensure continued compatibility.

### Will this work on Mac or Linux?

Currently, OmniPatch is a Windows-only desktop application. We do not have versions for macOS or Linux.

### Do I need an internet connection?

An internet connection is required only for downloading the patcher and potentially downloading specific patch files. The patching process itself can be performed offline.

### What should I do if my anticomponent flags the file?

Some security software may flag patching tools. You can add an exception for OmniPatch.exe or temporarily disable real-time scanning during use.

### Can this be used on multiple computers?

Yes, OmniPatch can be used on any compatible Windows machine where you have administrative privileges to install and modify applications.
